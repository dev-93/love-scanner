# 🔍 biz-love: 관계 분석 전문가

이 스킬은 Vue 3 + Vite 기반의 연애/관계 분석 서비스 성장을 지원합니다.

## 🎯 핵심 목표
- 사용자 인터랙션 기반의 관계 진단 UI/UX 최적화.
- 빠른 프로토타이핑 및 시장 반응 테스트.

## 📋 워크플로우
1. **프론트엔드 최적화**: Vue 3 Composition API를 활용한 빠르고 유려한 사용자 경험 구축.
2. **데이터 분석**: 관계 진단 로직의 정교화 및 결과 리포트 생성.
3. **수익성 테스트**: 다양한 분석 결과 제공 방식에 따른 유료화 가설 검증.
